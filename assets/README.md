# Assets

Store real hotel images here when you are ready to replace the temporary remote images.

Example:

1. Add a file such as `assets/images/hero.jpg`.
2. Open `constants.js`.
3. Change the relevant image value, for example:

```js
hero: "assets/images/hero.jpg"
```

The website reads image paths from `constants.js`, so most content updates should happen there instead of inside the HTML.
